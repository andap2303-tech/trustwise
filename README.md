# Trustwise — Charity Investment Copilot

Group project for **KX09 Data Science for Asset Management** (ESCP Business School, MiM, London, 2026).

Trustwise helps UK charity trustees answer one question:
> *How much of our cash can we safely invest, in what, and how bad could a bad year be in pounds?*

- **Five-pager (PDF):** [`Trustwise_Five_Pager.pdf`](Trustwise_Five_Pager.pdf)
- **Live demo:** https://trustwiser.netlify.app/

## Repository structure
| Folder / file | What it contains |
|---|---|
| `notebook/Trustwise_Project.ipynb` | The whole project in one Jupyter notebook: **Part A** analysis → **Part B** business plan → **Part C** builds the PDF |
| `notebook/Charity_Copilot_Financials_v3.xlsx` | The 36-month financial model in Excel (same numbers as Part B) |
| `website/` | Source code of the demo website (React + TypeScript + Vite); `website/dist/` is the built site |
| `Trustwise_Five_Pager.pdf` | The final document, generated by the notebook |

## Methods (course sessions)
| Step | Method | Session |
|---|---|---|
| Data cleaning and EDA | Yahoo Finance prices of 9 London ETFs, pence/pound fix, volatility, Sharpe ratio, beta, correlation | 2 |
| Portfolio | Efficient frontier, tangency portfolio, Capital Allocation Line, y* = (E[Rp] − Rf) / (A·σ²) | 2, 4 |
| Risk | GARCH(1,1) volatility forecast, 95% VaR and CVaR (prudent, zero mean) | 3, 8 |
| Stress tests | 2008, 2020 and 2022 crashes with long-history proxy ETFs | 8 |
| Backtest | Out-of-sample, expanding window, yearly re-estimation from 2020 | 9 |
| Market sizing | K-means on the Charity Commission register (elbow + silhouette) | 5–6 |

## How to run
**Notebook:** open `notebook/Trustwise_Project.ipynb` in Google Colab → *Runtime → Run all* (3–5 minutes). It downloads all data itself and writes `Trustwise_Five_Pager.pdf`.

**Website:** install Node.js, then
```bash
cd website
npm install
npm run dev      # local preview
npm run build    # creates website/dist
```
All website numbers come from the notebook (`website/src/lib/engine.ts`).

## Data sources
Yahoo Finance (ETF prices) · justETF (fund details) · Charity Commission for England and Wales, Register of Charities (open data) · Bank of England · ONS · Broadstone (2024) · RSM (2024) · Brewin Dolphin · SaaS benchmarks (First Page Sage, Lighter Capital, Benchmarkit). Full list on page 5 of the PDF.

## Limitations
Short history (2014–2026, mostly a bull market) · USD proxies in the stress tests · normal-distribution VaR (next step: Student-t GARCH) · the register has no cash data, so K-means uses the spending ratio as a proxy · the business model uses median SaaS benchmarks, not real customer data.
